## Architectural Principles (Always-On)

1. Protocol is passive infrastructure — 0.5%+0.5% from payouts at escrow release, never added to buyer's total.
2. Federation is the goal from day one.
3. Cryptographic identity (secp256k1) — protocol never holds passwords/keys/KYC docs.
4. Nostr is plumbing, Rangkai owns UX and search.
5. Small business first — hide complexity. If something seems hard, check for the simpler framing first.
6. Bitcoin is the invisible rail — v1 pays out BTC/USD directly, invisible conversion is v1.5 (R11).
7. Terminology: seller, buyer, logistics — not vendor, provider, courier.
8. No centralized consolidation hubs — logistics stays inside the decentralized pool.

## Troubleshooting Reference

### API Server Won't Start
`Router.use() requires a middleware function but got a Object` → empty/misconfigured route file in `routes/index.ts`.

### "TypeError: fetch failed" on Startup
Supabase paused — restore at supabase.com/dashboard.

### SDK changes not taking effect
D25 fixed S37 — just run `cd packages\sdk && npm run build`. If still not working, verify junction exists: `dir node_modules\@rangkai` should show `<JUNCTION>` not `<DIR>`.

### Seller re-login required after long gap
Expected if token expired during an overnight break. B3 fixed S37 handles server restarts within a session. Tokens are 36h — a gap longer than that requires re-login.

### Country field in checkout or ProductForm not storing ISO code
CountryCombobox (D19, S36) is in place — user must select from the dropdown, not just type and leave.

### Direct quote request blinks back to browse state
Check API server terminal for the error. With D19 in place this should no longer happen for country validation failures.

### Wrong provider showing in logistics-marketplace header
D34 fixed S36. `ProviderContext` now calls `GET /api/v1/logistics/providers/me` directly.

### Buyer sees wrong shipping price in cart
D35 fixed S36. `getAcceptedQuoteForProduct()` filters to `context = 'seller_standing'`.

### Order detail page showing subtotal and total but no shipping line
D36 fixed S36. Only renders when `logisticsCost > 0`.

### Trust/sanctions endpoint returns UNAUTHORIZED
Need a real Bearer token. Login first:
```
curl -s -X POST http://localhost:3000/api/v1/identity/login -H "Content-Type: application/json" -d "{\"email\":\"testBit2@test.com\",\"password\":\"bitshop123\"}"
```
Use the `token` field from the response.

### KYC registration blocked unexpectedly
Check `sanctions_checks` table for the DID — if `action: blocked`, the name matched a sanctions list entry at >95% confidence. Check `sanctions_list` for false positives.
